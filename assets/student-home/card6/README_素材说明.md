# Card 6 学生首页视觉素材包 v2

本包基于两张已确认效果图整理，包含 **5 张模块插画、栏目标题、模块标题、金币与奖励元素、头像、路线节点、角色与宝箱、底部入口、答题页按钮、完整参考卡片和实现说明**。

## 目录

- `scenes/`：五个首页模块的独立插画层，优先用于正式实现。
- `ui/section-titles/`：三个栏目木牌、空白木牌和五个模块标题字样。
- `ui/coins-rewards/`：金币、星星和奖励徽章。
- `ui/bottom-nav/`：底部三个入口的整块按钮与图标版。
- `ui/profile/`：姐姐头像、学习称号、顶部统计参考。
- `ui/quiz/`：词汇探险答题页可复用按钮与装饰。
- `decorations/`：探险角色、宝箱、路线节点、书本等独立装饰。
- `reference-cards/`：从确认图直接裁出的五张完整卡片，仅适合固定文案或像素级比对。
- `references/`：两张原始确认图。
- `docs/student-home-tokens.css`：从参考图取样的配色变量和横屏基础规则。
- `asset-manifest.json`：文件尺寸和用途清单。
- `给Codex的新说明.md`：可直接交给 Codex。

## 使用优先级

1. 正式实现优先用 `scenes/`、图标素材和真实 HTML 文案。
2. 栏目标题可直接使用固定文字图；更推荐使用 `wood-plaque-blank.png` 加 HTML 文字。
3. 金币数、题数、进度、状态文案必须是 HTML，不能烤进图片。
4. `reference-cards/` 只用于对照和固定文案兜底，不要把整个首页做成截图。
5. 任何已有素材可用时，禁止 Codex 重新画内联 SVG 或用 emoji 代替。

## 重要说明

- 补充元素主要是从确认图直接裁切，部分保留原卡片的浅色局部背景；在同色卡片内使用最稳妥。五张 scenes 插画带透明通道，适合正式响应式布局。
- 五张 `scenes/` 是重建插画，适合响应式布局；卡片框、标题、按钮仍由 CSS/HTML 完成。
- iPad 主验收方向必须是横屏：1024×768、1180×820、1194×834。
